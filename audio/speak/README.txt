Natural voice files for speaking exercises.

The app plays a real recording automatically when a file exists here.
Name each file: <pack-id>-<line-number>.mp3
Example: sp-intro-1.mp3 (first sentence of the "Introducing yourself" pack)

Create them with any natural text-to-speech tool (for example Microsoft Edge's
read-aloud voices, or a cloud TTS service), export as MP3, and copy them into this folder.
If a file is missing, the app falls back to the browser voice.
